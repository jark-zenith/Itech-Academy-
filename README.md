# ITech Academy

**Don't Just Watch Technology. Build It.**

ITech Academy is the education concept of JARK Industries / the Pruden ecosystem: a practical technology-learning platform where students learn by building, experimenting, asking questions and solving real problems.

## Vision
The Academy grows learners from ICT foundations into software development, AI, cybersecurity, robotics/IoT, creative technology and entrepreneurship.

## Learning model
**Learn → Experiment → Build → Share**

## Tracks
- ICT Foundations
- Software Development
- AI & Intelligent Systems
- Cybersecurity
- Robotics & IoT
- Creative Technology
- Future advanced engineering tracks

## J.A.R.K integration
The Academy is designed so the future J.A.R.K intelligent assistant can become the in-platform tutor: explaining concepts, guiding projects, helping debug, remembering learning progress and supporting builders.

## Current build
A lightweight, dependency-free responsive Academy shell using HTML, CSS and JavaScript. Open index.html in a browser.
