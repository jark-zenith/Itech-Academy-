# ITech Academy (Android)

> **"Don't Just Watch Technology. Build It."**

ITech Academy is an Android application built with Kotlin and Jetpack Compose. It delivers a project-first learning platform for builders, engineers, and creators.

## Key Features

- **Academy Home**: Hero overview, interactive 4-stage learning tracks (Foundation, Builder, Engineer, Innovator), and live Academy Terminal with system diagnostics.
- **Curriculum & Practical Build Paths**: ICT Foundations, Software Development, AI & Intelligent Systems, Cybersecurity & Defense, and Robotics & IoT with practical lessons, interactive challenges, code view, and progress tracking.
- **AI Faculty & J.A.R.K Smart Router**: Multi-specialist AI faculty (J.A.R.K Lead Orchestrator, Claude Code Mentor, ChatGPT Research Mentor, Gemini Innovation Mentor, Cyber Mentor, Project Lab Coach, Exam Coach) with natural task routing and step-by-step guidance.
- **Project Lab & Portfolio**: Hands-on milestones, challenge starter tracks, and portfolio submissions.
- **Academy OS**: Role-aware spaces for **Admin** (User directory, AI policy control, security center, live audit trail), **Teacher** (Course management, student roster, submissions reviewer & grading), and **Student** (My Learning paths, progress metrics, certificates).

## Tech Stack

- **Platform**: Android (minSdk 26, targetSdk 35)
- **UI Framework**: Jetpack Compose with Material Design 3
- **Language**: Kotlin 2.1.10
- **Build System**: Gradle 9.3.1 (Kotlin DSL)
